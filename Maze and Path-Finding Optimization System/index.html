Theory: time and space complexity

V = number of open cells, E = number of connections (about 4V on a grid).

AlgorithmTechniqueTimeSpaceShortest path?
BFSQueue, level by levelO(V + E)O(V)Fewest steps. Not cheapest on weighted maps.
DFSStack, go deep firstO(V + E)O(V)No. Finds a path, usually a long one.
DijkstraMin-heap on distance g(n)O((V + E) log V)O(V)Yes, lowest cost (non-negative weights).
A*Min-heap on g(n) + h(n), Manhattan hO((V + E) log V) worst caseO(V)Yes, since h never overestimates. Usually explores far fewer nodes.
