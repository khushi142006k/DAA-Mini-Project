COMPLEXITY NOTES

How to interpret the results

  • BFS: explores level by level; finds a shortest path when every move has equal cost.
  • DFS: explores deeply before backtracking; does not guarantee a shortest path.
  • Dijkstra: expands the lowest known path cost; optimal for non-negative edge costs.
  • A*: uses path cost + Manhattan-distance heuristic; optimal here with unit-cost 4-way movement.

THEORY

Time & space complexity

For a graph with V cells and E valid neighbor links:

BFS / DFSO(V + E)
DijkstraO((V + E) log V)
A*O((V + E) log V)*
*Typical priority-queue implementation; A* worst-case behavior can still be exponential with some heuristic/search formulations.
